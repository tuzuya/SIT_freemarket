# タスク一覧

このファイルは `/coding <タスク名>` で呼び出したとき、AIが参照する実装メモです。
AIも自分でも自由に編集してください。タスクを追加するときは既存フォーマットに従ってください。

---

## 使い方

```
/coding ログアウト
/coding 機能2
/coding SOLD表示
```

タスク名またはキーワードを渡すと、このファイルから該当タスクを見つけて実装に入ります。

- `[ ]` 未着手
